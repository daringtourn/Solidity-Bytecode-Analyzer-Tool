## What This Tool Does

- Disassembles EVM bytecode into opcodes
- Parses and displays contract metadata and immutables
- Visualizes control flow and function boundaries
- Detects known patterns and vulnerabilities
- Compares bytecode between different versions
- Imports bytecode from transaction, file or clipboard
- Exports analysis report to JSON and HTML
- Supports legacy and Shanghai EVM opcodes
- Works on Windows 10 and Windows 11

Solidity Bytecode Analyzer is a professional tool for smart contract developers, auditors and security researchers who need to understand compiled contract bytecode. It provides disassembly, control flow visualization and pattern detection. This is a fully functional application with no limitations.
